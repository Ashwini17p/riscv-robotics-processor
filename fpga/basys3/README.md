# Basys 3 implementation files

| File | Purpose |
|---|---|
| `riscv_fpga_top.v` | Top level: button debounce / single-step clock, CPU, LEDs, ILA |
| `basys3.xdc` | Pin and clock constraints |
| `ip/ila_0/ila_0.xci` | ILA debug core (regenerated by the Tcl script) |
| `rtl_overrides/` | FPGA-specific variants of `t1_riscv_cpu.v` and `reg_file.v` |
| `create_project.tcl` | Recreates the Vivado project in `build/vivado` |
| `reports/` | Utilization, power and route-status reports from the implementation run |

```bash
vivado -mode batch -source fpga/basys3/create_project.tcl
```
