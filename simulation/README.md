# Simulation

| Script | What it does |
|---|---|
| `run_t1c.sh` | Compiles and runs the 38-check CPU testbench with Icarus Verilog |
| `run_unit_tests.sh` | Runs the ALU / PC / register-file unit benches |
| `modelsim_t1c.do` | Same CPU test for ModelSim / Questa (run from the repo root) |
| `legacy/` | Earlier copy of the PC testbench, kept for reference |

Build products go to `build/` (git-ignored).
